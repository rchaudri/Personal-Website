The CFO Agent
at Trivium

I built an agent that processed income statements, balance sheets, cash-flow statements, and other financial documents to generate insights, industry benchmarks, forecasts, and tailored recommendations.

The workflow also generated and executed code to create graphs dynamically, replacing manual graph assembly.

An analytical workflow

The application connected financial-document analysis with visual outputs. Dynamic graph generation made the output responsive to analytical questions.

An approachable interface

The wider Trivium work included user workflows and interactive wireframes for self-service analytics. The application included privacy controls for sensitive financial data.
